  • Well Selector cells are square again, the same size they are today, and the grid stays centred in its dock exactly as now.
  • On Ubuntu the skin is pixel-for-pixel the same: it's a Qt stylesheet plus palette, so nothing in it depends on Windows. Only the typeface differs, because the skin asks for the system UI font and gets Ubuntu there instead of Segoe UI. Pick the Ubuntu button above to see that.
  • Dark mode is a manual switch in the Settings menu, remembered between sessions. A "follow the OS" option is possible on both platforms later (Windows registry on one side, the GNOME colour-scheme key on the other), but it isn't part of the first cut.
  • The purple pyqtgraph dock bars become quiet card headers with a grip; the docks still drag and resize exactly as now.
  • Live and Start Acquisition are the only filled accent buttons, so the eye finds the two actions that matter.
