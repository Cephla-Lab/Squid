# Squid UI Skin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Squid a Fluent-style "soft native" skin with Light (default) and Dark themes and an exact Classic fallback, switchable from Settings > Appearance and persisted in the machine ini, without changing layout or behaviour.

**Architecture:** One new module, `software/control/theme.py`, owns every colour, radius and font decision as tokens, generates one application stylesheet plus a matching `QPalette`, and applies them through a `ThemeManager` singleton. Widgets stop carrying literal colours: they get *roles* (dynamic properties the stylesheet styles) through `theme.set_role(...)`, and code that paints rows or builds styles from colours reads `theme.manager().tokens()` and re-applies on `theme_changed`. Classic applies no stylesheet and the default palette and font, and every role and token resolves to today's literal, so Classic is pixel-identical to the current app.

**Tech Stack:** Python 3.12, PyQt5 5.15 through `qtpy` (PyQt6 must keep working), pyqtgraph 0.14 dock area, pytest + pytest-qt, Pillow for screenshot comparison. No new runtime dependency.

**Spec:** `docs/superpowers/specs/2026-11-08-ui-skin-design.md`

## Global Constraints

- No new runtime dependency. Hand-written QSS and `QPalette` only. Every Qt import goes through `qtpy`; `theme.py` must not import `PyQt5` or `PyQt6` directly.
- Layout, widget hierarchy and behaviour are unchanged. No layout-margin edits. Cards get only a 1 px border from the stylesheet.
- Light is the default theme. Persisted as `[GENERAL] ui_theme = light | dark | classic` in the machine ini; read through `control._def.UI_THEME`.
- Light ↔ Dark apply immediately. Entering or leaving Classic saves, offers the existing restart path, and applies at next start.
- Classic is pixel-faithful: no application stylesheet, Qt's default palette and font, and every role/token resolves to the literal string or colour the code uses today.
- Windows font in Light/Dark: `QFont("Segoe UI", 8)`. Linux: `QFontDatabase.systemFont(QFontDatabase.GeneralFont)`. Classic: the application's default font captured before any theme is applied.
- Length tokens are logical px at 96 dpi. The stylesheet multiplies them by `logicalDotsPerInchX() / 96` of the primary screen when `devicePixelRatio() == 1`, else by 1.
- Content colours stay literal: channel colour swatches, colour-picker buttons, laser/VersaLase status dots and the per-head status colours (`GREEN`, `AMBER`, `RED`, `GREY` constants).
- Image canvases (napari viewers, live view, LUT strip, pyqtgraph plots) stay dark in all themes; the navigation viewer is out of scope.
- Tokens, exactly as the spec tables give them (Light / Dark): ground `#f3f3f3`/`#202020`, surface `#fbfbfb`/`#2b2b2b`, header `#f6f6f6`/`#272727`, border `#e5e5e5`/`#3a3a3a`, text `#1a1a1a`/`#f0f0f0`, muted `#5f5f5f`/`#a6a6a6`, input_bg `#ffffff`/`#333333`, input_border `#e0e0e0`/`#454545`, input_border_bottom `#8a8a8a`/`#9a9a9a`, button_bg `#fbfbfb`/`#353535`, button_border `#d9d9d9`/`#474747`, accent `#0067c0`/`#4cc2ff`, accent_text `#ffffff`/`#0b1a24`, accent_soft `#e8f1fb`/`rgba(76,194,255,0.16)`, band `#f7f9fc`/`#30343a`, band_border `#e5e5e5`/`#3d4148`, tab_tray `#ececec`/`#262626`, tab_selected `#ffffff`/`#3c3c3c`, warning_bg `#fff4ce`/`#3d3200`, warning_text `#8a5a00`/`#ffd45c`, warning_border `#f5dd9a`/`#5a4a00`, thumb `#ffffff`/`#2b2b2b`.
